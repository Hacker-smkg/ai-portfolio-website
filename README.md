# Next-Gen AI Portfolio

A highly interactive, physics-driven Next.js portfolio showcasing expertise in Generative AI, microservices, and modern frontend tools.

**🚀 Live Demo:** [View Deployment on Vercel](https://ai-portfolio-website-git-main-hackersmkgs-projects.vercel.app)

## Features

- **Quantum UI Cursor**: A custom glowing orb built with Framer Motion that trails the mouse and magnetically snaps to interactive elements, featuring dynamic blending modes.
- **Interactive Repulsion Physics**: A custom HTML5 Canvas particle system where neural-network nodes actively repel away from the cursor in real-time, creating a fluid, high-tech experience.
- **Parallax Hero with Cyber-Glitch Typography**: An advanced hero section featuring deep-background floating blur-spheres mapped to scroll behavior, a custom SVG brain vector graphic that reacts to hover states, and RGB-split glitch-art typography on key text elements.
- **3D Tilt Projects**: Algorithmic 3D tilt tracking (`perspective` and `preserve-3d`) on project cards. The cards calculate mouse X/Y coordinates to physically rotate and tilt toward the user when hovered.
- **Glassmorphism & Neon Aesthetics**: Premium styling utilizing deep blacks, vibrant cyan/purple gradients, and backdrop blurs to achieve a "next-gen" AI developer vibe.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4, Custom CSS (Glassmorphism, 3D Utilities)
- **Animations & Physics**: Framer Motion
- **Deployment**: Vercel

## Local Development

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
